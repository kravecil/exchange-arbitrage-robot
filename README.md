Межбиржевой арбитражный робот (Crypto Arbitrage Bot)
Робот для поиска и исполнения арбитражных ситуаций между разными криптовалютными биржами. Проект написан на Python 3.12 с использованием асинхронной библиотеки ccxt и пакетного менеджера uv.

Возможности
Работа с любыми биржами, поддерживаемыми ccxt (Binance, Bybit, OKX и др.).
Поддержка всех возможных общих торговых пар с возможностью исключения или явного включения.
Учет комиссий биржи (taker fee) при расчете прибыльности.
Гибкая настройка минимального порога прибыли (в процентах).
Два режима работы:
dry_run (тестовый): только выводит возможности в консоль без реальных сделок.
Реальный: совершает рыночные покупки/продажи.
Требования
Python 3.12+
uv (быстрый пакетный менеджер для Python)
Установка
Убедитесь, что у вас установлен uv. Если нет, установите его:
curl -LsSf https://astral.sh/uv/install.sh | sh
Создайте виртуальное окружение и установите зависимости с помощью uv:
uv venvuv pip install -r pyproject.toml
Настройка
Все настройки находятся в файле config.json.

Параметры:
dry_run (true/false): Если true — бот только выводит информацию о сделках в консоль. Если false — совершает реальные сделки.
trade_amount_usdt: Сумма в USDT, которая будет использоваться для каждой арбитражной сделки.
min_profit_threshold: Минимальный порог прибыли в процентах, при котором бот будет сигнализировать/сделать ставку (с учетом комиссий).
check_interval_seconds: Задержка между проверками рынков в секундах.
exchanges: Список бирж. Для добавления новой биржи просто добавьте её название (как в ccxt, например gateio, kraken), укажите API ключи и установите "enabled": true.
symbols:
use_all_common: Если true, бот найдет все пары, которые существуют на всех включенных биржах одновременно.
include: Список пар для работы, если use_all_common = false (например ["BTC/USDT", "ETH/USDT"]).
exclude: Список пар, которые нужно исключить из сканирования (работает, если use_all_common = true).
Запуск
После настройки config.json выполните:

uv run python main.py
⚠️ Важные замечания по реальной торговле
Балансы на биржах: Для осуществления реального межбиржевого арбитража (покупка на бирже А, продажа на бирже Б) у вас должны быть заблаговременно распределены депозиты. На бирже А должен быть USDT для покупки, а на бирже Б — базовая криптовалюта (например, BTC) для продажи. Бот использует рыночные ордера (Market) для мгновенного исполнения.
Вывод средств: Робот не переводит активы между биржами. Вывод средств и пополнение балансов вы должны контролировать самостоятельно.
Риски: Криптовалютные рынки очень волатильны. Задержки в сети или API могут привести к убыткам (проскальзывание цены). Тщательно тестируйте бота в режиме dry_run.
