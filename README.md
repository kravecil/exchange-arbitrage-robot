# Exchange Arbitrage Robot

Межбиржевой арбитражный робот: мониторит цены на нескольких криптобиржах через [ccxt](https://github.com/ccxt/ccxt), находит расхождения и либо выводит возможности в консоль (тестовый режим), либо исполняет сделки (боевой режим).

## Возможности

- **Два режима работы**
  - `paper` — тестовый режим без реальных сделок, только вывод найденных возможностей
  - `live` — реальное размещение рыночных ордеров (требуются API-ключи)
- **Простое добавление бирж** — достаточно указать `id` ccxt в `config.yaml` (Binance, Bybit, OKX и др.)
- **Гибкая настройка торговых пар** — мониторинг всех общих пар или явный список `include` / `exclude`
- **Пороги спреда** — отдельные настройки `min_spread_percent_up` и `min_spread_percent_down`
- **Учёт комиссий** — чистый спред рассчитывается с taker-комиссиями бирж

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) — менеджер пакетов

## Быстрый старт

### 1. Установка зависимостей

```bash
uv sync
```

### 2. Конфигурация

```bash
cp config.example.yaml config.yaml
cp .env.example .env
```

Отредактируйте `config.yaml`:

```yaml
mode: paper

scanner:
  poll_interval_seconds: 10
  min_spread_percent_up: 0.5
  min_spread_percent_down: 0.5
  include_fees: true
  quote_currencies:
    - USDT

symbols:
  include: []       # пусто = все общие пары
  exclude: []

exchanges:
  - id: binance
    enabled: true
  - id: bybit
    enabled: true   # для арбитража нужно минимум 2 биржи
```

### 3. Запуск

```bash
uv run arbitrage-robot
```

Один цикл сканирования (без бесконечного цикла):

```bash
uv run arbitrage-robot --once
```

Альтернативный способ запуска:

```bash
uv run python -m arbitrage_robot
```

## Добавление бирж

Биржи добавляются в секцию `exchanges` файла `config.yaml`. Используйте `id` из [списка ccxt](https://docs.ccxt.com/#/README?id=exchanges):

```yaml
exchanges:
  - id: binance
    enabled: true

  - id: bybit
    enabled: true

  - id: okx
    enabled: false   # включите, когда будете готовы
```

Для режима `live` добавьте ключи в `.env`:

```env
BINANCE_API_KEY=ваш_ключ
BINANCE_API_SECRET=ваш_секрет

BYBIT_API_KEY=ваш_ключ
BYBIT_API_SECRET=ваш_секрет

OKX_API_KEY=ваш_ключ
OKX_API_SECRET=ваш_секрет
OKX_API_PASSPHRASE=ваша_фраза
```

Шаблон имён: `{ID_БИРЖИ}_API_KEY`, `{ID_БИРЖИ}_API_SECRET`, `{ID_БИРЖИ}_API_PASSPHRASE` (если нужна бирже).

## Настройка торговых пар

| Параметр | Описание |
|---|---|
| `symbols.include` | Явный список пар (`BTC/USDT`, `ETH/USDT`). Пустой список — все общие пары включённых бирж |
| `symbols.exclude` | Пары, исключённые из мониторинга |
| `scanner.quote_currencies` | Фильтр по котировочной валюте (`USDT`, `USDC`, `BTC` и т.д.) |

Пример — только BTC и ETH к USDT:

```yaml
symbols:
  include:
    - BTC/USDT
    - ETH/USDT
  exclude: []
```

## Пороги спреда

| Параметр | Описание |
|---|---|
| `min_spread_percent_up` | Минимальный чистый спред (%) для направления «вверх» |
| `min_spread_percent_down` | Минимальный чистый спред (%) для направления «вниз» |
| `include_fees` | Вычитать taker-комиссии из спреда |

Направление определяется парой бирж (buy → sell): для разных комбинаций можно задавать разные пороги чувствительности.

## Режимы работы

### Paper (тестовый)

```yaml
mode: paper
```

Робот выводит в консоль сообщения вида:

```
[PAPER] BTC/USDT: купить на binance @ 95000.0, продать на bybit @ 95480.0 | спред 0.5053% (чистый 0.3053%), направление вверх, комиссии 0.1% + 0.1%
```

API-ключи не требуются — используются только публичные данные о ценах.

### Live (боевой)

```yaml
mode: live
```

Робот размещает рыночные ордера на обеих биржах. **Используйте на свой страх и риск.** Учитывайте:

- проскальзывание и задержки сети
- необходимость иметь баланс на обеих биржах
- лимиты API и комиссии вывода средств
- риск частичного исполнения

## Как работает арбитраж

1. Робот подключается к включённым биржам и загружает рынки.
2. Находит торговые пары, доступные на **всех** включённых биржах.
3. На каждом цикле запрашивает bid/ask цены.
4. Для каждой пары сравнивает цены между биржами: покупка по ask на одной, продажа по bid на другой.
5. Если чистый спред превышает порог — передаёт возможность исполнителю (`paper` или `live`).

## Ограничения

- Межбиржевой арбитраж требует **минимум 2 включённые биржи**.
- Робот не учитывает время перевода средств между биржами.
- Не гарантирует прибыль — цены меняются быстрее, чем исполняются ордера.
- Перед боевым режимом рекомендуется длительное тестирование в `paper`.
