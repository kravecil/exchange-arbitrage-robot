# 🤖 Inter-Exchange Arbitrage Bot (Futures)

Профессиональный асинхронный бот для поиска и исполнения межбиржевого арбитража фьючерсных контрактов. Написан на Python с использованием `ccxt`, `asyncio` и `pydantic`.

## 🌟 Особенности

- **Асинхронность:** Использование `asyncio` и `ccxt.async_support` для молниеносного опроса множества бирж.
- **Гибкость:** Легкое добавление новых бирж и торговых пар через `config.yaml`.
- **Безопасность:** Режим `paper` (симуляция) для тестирования стратегий без риска потери средств.
- **Учет комиссий:** Автоматический расчет чистой прибыли с учетом taker-комиссий бирж.
- **Фильтрация:** Whitelist и Blacklist для торговых пар.
- **Красивый UI:** Вывод результатов в консоль с использованием `rich`.
- **Фьючерсы:** Работа с фьючерсными контрактами (PERP и квартальные контракты).

## 🛠 Технологии

- **Python 3.11+**
- **uv** - сверхбыстрый пакетный менеджер
- **ccxt** - унифицированный API для криптобирж
- **pydantic** - валидация настроек
- **rich** - форматирование консольного вывода

```uv sync```

### 3. Настройка

Скопируйте или создайте файл config.yaml и заполните его:

```yaml
mode: "paper" # Замените на "live" для реальной торговли

```

### 4. Запуск

```bash
uv run arb-bot
```

## ⚙️ Как это работает (Фьючерсы)
1. При старте бот подключается к указанным биржам и загружает списки активных фьючерсных рынков.
2. Находит пересечение торговых пар фьючерсов (например, если на Binance есть `BTC/USDT:USDT` и на Bybit есть `BTC/USDT:USDT`, она пойдет в анализ).
3. Асинхронно запрашивает актуальные тикеры (цены Bid/Ask) для фьючерсов.
4. Для каждой пары фьючерсов ищет, где можно купить дешевле (Ask) и где продать дороже (Bid).
5. Вычисляет спред и вычитает комиссии за торговлю (taker fees).
6. Если чистая прибыль превышает `min_profit_percent`, бот сигнализирует об этом (или исполняет сделку в режиме `live`).

## ⚠️ Важные предупреждения для режима LIVE (Фьючерсы)
1. **Баланс на биржах:** Для истинного арбитража у вас должны быть средства (например, USDT) **на обеих биржах одновременно**. Это позволяет покупать и продавать одновременно, избегая риска "одной ноги" (когда одна биржа исполняет ордер, а цена на второй уже ушла).
2. **Лимиты API:** Убедитесь, что ваши API ключи имеют права на торговлю, но НЕ имеют прав на вывод средств (на случай утечки ключей).
3. **Скрытые комиссии:** Бот учитывает торговые комиссии (taker), но не учитывает комиссии за ввод/вывод крипты между биржами. При использовании метода с переводом крипты обязательно закладывайте комиссии сети и время транзакции.

### Как запустить и проверить

1. Убедитесь, что вы находитесь в корневой директории проекта.
2. Выполните синхронизацию зависимостей через `uv`:
   ```bash
   uv sync
   ```
3. Отредактируйте `config.yaml` (добавьте хотя бы две биржи, например, Binance и Bybit. Для теста в режиме `paper` API ключи можно оставить пустыми, но некоторые биржи могут требовать их даже для чтения тикеров).
4. Запустите бота:
```bash
uv run arb-bot
```

### Как добавить новую биржу (например, OKX)
Вам не нужно трогать код! Просто откройте `config.yaml` и добавьте блок:

```yaml
  - id: okx
    apiKey: "YOUR_OKX_API"
    secret: "YOUR_OKX_SECRET"
    password: "YOUR_OKX_PASSPHRASE" # OKX требует passphrase
```
